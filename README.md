# Allumé landing page

Static one-page site. No build step.

- `index.html` — all markup, styles and script
- `assets/img/` — gallery photos (web-sized)
- `assets/fonts/` — self-hosted fonts (Mr Dafoe, Bodoni Moda, Jost; SIL Open Font License)
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Publish on GitHub Pages

1. Create a repository and upload everything in this folder to the root of the `main` branch.
2. Repository Settings → Pages → Source: "Deploy from a branch" → `main` / root.
3. For a custom domain, add it under Settings → Pages and add a `CNAME` file containing the domain.

All booking buttons link to https://holidayislandlodging.com/.
